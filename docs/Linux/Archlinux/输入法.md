# Fcitx5输入法配置介绍

## 前言：为什么选择Fcitx5？

在 Linux 桌面里，输入法是最影响日常体验的基础设施之一。

**fcitx5** 是新一代输入法框架，也是 fcitx4 的彻底重写，他有以下优势：

- 核心用 C++ 编写，轻量、启动快
- 插件化架构，按需加载输入法引擎和界面组件
- 原生支持 Wayland，候选框定位和兼容性更好
- 中文生态完整：拼音、双拼、五笔、Rime 等

相比已基本停更的 fcitx4，以及偏重且与 GNOME 绑定较深的 IBus，fcitx5 在性能、Wayland 适配和可定制性上更均衡，因此成为我在 Linux 下配置中文输入的首选。

> 本文记录我的配置过程与常用设置，希望能帮你少走一些弯路。  

> 注意，本文的一些软件包可能会用到archlinuxcn源，所以我默认你已经有了archlinuxcn源，如果你没有的话，请先添加源后再继续看。

## How to do?

### 一、安装与配置
``` bash
sudo pacman -S fcitx5-im fcitx5-rime rime-ice-pinyin 
```
> `fcitx5-im`是fcitx5的主程序，他包含了fcitx5本体和部分输入法模块，可以实现开箱即用

> `fcitx5-rime`是一个fcitx5的输入法方案，更适合中国宝宝的体质，唯一美中不足的是他默认繁体中文

>`rime-ice-pinyin`是rime的雾凇拼音方案，他是一个简体中文方案，更适合在大陆环境中使用，当然缺点是他的联想功能很烂，可能需要自己优化

**安装好后我们需要进行一些配置来启用fcitx5和雾淞拼音**

#### Fcitx5

KDE用户可以在系统设置中找到输入法配置，将中州韵（Rime）移至输入法左边来启用  
使用Fcitx5 Configtools的用户可以在configtool中将中州韵（Rime）移至输入法左边来启用

#### 雾凇拼音
使用雾凇拼音需要编辑一下配置文件，你需要在`~/.local/share/fcitx5/rime`目录（这个目录需要你自己创建）下创建一个`default.custom.yaml`文件，在文件中写入以下内容
```bash
patch:
    __include:  rime_ice_suggestions:/
    __include: wanxiang_suggestions:/
```
然后确保你已经启用rime，重启一下fcitx5后就可以使用了
> Fcitx5的启动命令为`fcitx5 -d`

**到此，Fcitx5的配置就全部结束了，是的，配置Fcitx5的输入法就是这么简单！**

### 二、美化
现在你的输入法已经可以使用了，但是他的输入框和字体都是默认的，很不美观，但你可以同过美化的方式让fcitx5变革更美观一些，打造一个属于你自己独特的fcitx5输入法。  

#### 1.输入框皮肤
我会推荐一些好看的输入框皮肤来进行一些参考  
* [fcitx5-theme-mint](https://github.com/witt-bit/fcitx5-theme-mint "fcitx5-theme-mint" )：这是一个类似于薄荷输入法的皮肤，整体很简洁清新，而且不失细节，个人感觉比部分大色块似的皮肤好看

* [fcitx5-theme-wechat](https://github.com/witt-bit/fcitx5-theme-wechat "fcitx5-theme-wechat")：这是一个类微信输入法的皮肤，设计是否还原我不知道 *~~因为我没用过~~*，喜欢微信输入法的小伙伴可以试一下

* [fcitx5-theme-macos12](https://github.com/witt-bit/fcitx5-theme-macos12 "fcitx5-theme-macos12")：这是一个macOS风格的皮肤，也是我个人比较喜欢的一个，当然他可能会需要安装苹方字体来实现完全体，不过我用默认字体感觉也不错，可以尝试一下

主题设置的话，Fcitx Configtool的可以在附加选项的Classic User Interface里对主题进行更改，KDE或其他用户可以自己探索一下 *~~因为我不用KDE~~* ，主题更改后不需要重启

#### 2.输入法字体
你可以通过更改输入法字体来使输入框更美观，至于推荐的字体......这个只能自己探索了  

字体设置与主题设置在同一选项，大家可以自己进行更改，与主题更改一样，字体更改后也不需要重启

## 常见问题
Fcitx5虽然安装简单配置迅速，但是有的时候你也会碰见一些抽象的小问题，并且在解决的时候会异常的烦躁，怎么修都修不好，我会在这里整理一些我碰到过的小问题和解决方法，大家可以参考一下（会长期更新）

### 1.Linux QQ下的漏字母问题
这是一个Fcitx5的常见问题，在打字时会频繁的漏字母到聊天框里，本质上是你打字打太快了他没有捕捉到，但是在Electron应用中这种问题会非常明显，甚至是影响了使用体验。
* 解决方法：在`/etc/environment`中添加以下内容
```bash
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIRES=@im=fcitx
SDL_IM_MODULE=fcitx
```
完成后需要注销一下使环境变量生效

> 注意：Niri或者其他WM用户可以在窗口管理器配置文件里添加这些内容

### 2.微信无法使用输入法
在微信4.1.13后Wayland下微信可能无法使用输入法，因为微信的输入法支持模块只有X11没有Wayland，所以会导致输入法无法使用
* 解决方法：在`/etc/environbment`下添加一下内容
```bash
QT_IM_MODULE=text-input-unstable-v3
```
完成后需要注销一下使环境变量生效

> 注意：Niri或者其他WM用户可以在窗口管理器配置文件里添加这些内容
